# Rule-Based Chatbot Using Python

## Project Title
Rule-Based Chatbot Using Python

## Objective
To develop a simple chatbot that interacts with users by identifying their inputs through predefined rules and providing appropriate responses using Python conditional statements and basic text-processing techniques.

## Features
- **Greetings:** Responds to "hi", "hello", "hey".
- **Introduction:** Tells the user its name and purpose.
- **Status Check:** Responds to "how are you?".
- **Help:** Provides guidance on what it can do.
- **Exit:** Gracefully closes the conversation when the user says "bye", "exit", or "quit".
- **Default Response:** Handles unrecognized inputs politely.

## How to Run
1. Ensure you have Python installed.
2. Navigate to the project directory:
   ```bash
   cd rule-based-chatbot
   ```
3. Run the chatbot:
   ```bash
   python chatbot.py
   ```
